# atlas-local-face-recognition

Face recognition with [InsightFace](https://github.com/deepinsight/insightface) and MongoDB Atlas Local vector search.

Full walkthrough: [How to build your own three letter agency with InsightFace and Atlas Local vector search](https://jeroenvervaeke.com/articles/how-to-build-your-own-three-letter-agency-with-insightface-and-atlas-local-vector-search)

## Prerequisites

- [uv](https://docs.astral.sh/uv/)
- [Docker](https://www.docker.com/)

## Run

```sh
uv run marimo edit face-recognition.py
```

## Dataset

The profiles in `_dataset/` are AI-generated with [Higgsfield](https://higgsfield.ai?fpr=jeroen-6ca3b8) and free for everyone to use.
